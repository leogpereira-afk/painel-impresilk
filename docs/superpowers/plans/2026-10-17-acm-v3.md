# ACM v3 — implementação do prompt de auditoria aprovado

Autorizado em 17/10/2026. Implementação local, sem deploy. Spec de usuário completa disponível fora do repositório em /tmp/acm-auditoria-prompt-20261017.md. Base 3cd2ad4. Dados fictícios. Cálculos em mm. Não perder projetos antigos, permissões ou vínculo às O.S.

## Contratos e decisões

- Root integra ACMStudio.jsx, ACMForms.jsx, navegação e CSS geral. Três frentes isoladas por arquivos; nenhuma altera arquivo da outra sem coordenação. Revisão cruzada depois da integração. Não commitar/push pelos agentes.
- Dobras: preservar edge numérico legado. Novo edge objeto `{type:'fold',height:primeiroSegmento,folds:[{id,length,angle,direction,compensation?},...]}`. `length` é distância nominal entre linhas/successivo recorte no desenvolvimento; ângulo acabado e fresa são distintos. Agent do motor define contrato final e avisa root antes de UI. Múltiplas dobras não equivalem a calibração; invalidar calibração por mudança geométrica/processo. Deve existir representação montada coerente e duas linhas reais, não apenas anotação.
- Importação técnica: entidade independente `project.technicalDrawing` com `version:1`, `name`, `unit`, `tolerance`, `parts:[{id,width,height,contour:[[x,y]],holes:[{x,y,diameter}],grooves:[{x1,y1,x2,y2}],quantity}]`. Geometria normalizada mm, origem inferior esquerda, contorno fechado implícito. Importador confirma escala e reporta unsupported; não gera curvas espaciais a partir de imagens. Motor integra as peças planas compatíveis ao projeto em modo técnico separado da fachada, sem ignorar entidades desconhecidas. Calandragem/dobras 3D não desenvolvíveis permanecem referência explícita até possuírem contrato válido; permitido pelo prompt.
- Usar nesting conservador por envelope e declarar esse fato; não prometer ótimo global ou G-code. Não enfraquecer validação técnica para simular funcionamento.
